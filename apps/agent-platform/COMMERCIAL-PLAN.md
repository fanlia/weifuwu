> **状态**：📋 规划——待实施

## 1. 产品定位（一页纸）

**一句话**：给"需要 AI 干活但必须可控可审计"的组织提供企业级 AI Agent 工作平台。

**价值主张（按角色）**：

| 角色 | 价值主张 | 系统对应能力 |
|------|---------|-------------|
| 一线员工 | AI 同事在部门群里帮忙干活（问知识/跑任务） | 群聊 + 知识库 RAG + 沙盒工具 |
| 团队管理者 | AI 关键操作先过我的审批 | HITL Approvals 页 |
| 平台管理员 | 租户/工具/沙盒全治理，数据不出域 | 多租户 + Docker 沙盒 + 配额 |
| 老板 | 每天看 AI 花了多少、省了多少 | 成本金额化 + 趋势（已实现） |

**差异化护城河**（vs 直接用 DeepSeek/ChatGPT 网页版）：
1. **沙盒安全边界**——AI 执行在 Docker 容器内（`--network none` 默认），企业敢让 AI 碰真实文件
2. **HITL 审批闸门**——高风险操作人工批准
3. **多租户隔离**——部门/公司数据边界清晰
4. **成本可控**——Token 配额 + 金额化视图
5. **私有化部署**——数据不出客户机房

## 2. 目标市场与客户分层

### 2.1 市场分层

| 层 | 客户 | 规模 | 产品形态 | 客单价锚点 |
|----|------|------|---------|-----------|
| SMB | 中小型企业 | 10-200 人 | SaaS 订阅 | ¥5k-30k/年 |
| 中大型 | 成长型企业 | 200-2000 人 | SaaS + 专属版 | ¥10-50 万/年 |
| 行业/大客户 | 金融/医疗/政务/制造 | 2000+ 人 | 私有化授权 | ¥20-100 万/年 |

### 2.2 采购驱动者与决策链

```
老板（预算/ROI）→ IT 负责人（安全/集成）→ 业务负责人（场景/效率）→ 合规/法务（审计）
```

- **老板**看：成本视图（已具备）、人力节省 ROI（**缺：ROI 视图**）
- **IT** 看：SSO（缺）、审计日志（缺）、私有化（具备）、沙盒安全（具备）
- **业务**看：开箱即用的场景模板（缺：模板化 Agent）
- **合规**看：审批留痕（具备）、数据导出（缺）、租户隔离（具备）

## 4. 商业模式（三层收入）

```
┌──────────────────────────────────────────────────────────┐
│ ① SaaS 订阅（线上成交 · 验证 PMF · 现金流）                │
│    免费版 → Pro（席位 + 用量）→ 企业版（专属）               │
│    毛利来源：模型代购加价（1.3-1.5×）+ 席位费               │
├──────────────────────────────────────────────────────────┤
│ ② 私有化授权（大单 · 利润主力）                            │
│    年授权费 + 实施服务费 + 年度维护（15-20%）               │
│    Dockerfile 已就绪——补 License + 白标 + 文档            │
├──────────────────────────────────────────────────────────┤
│ ③ 增值服务（利润补充）                                    │
│    沙盒安全审计报告 / 管理 API / SSO 集成 / 专属模型通道    │
└──────────────────────────────────────────────────────────┘
```

### 4.1 SaaS 订阅分层（建议）

| 版 | 价格锚点 | 功能 |
|----|---------|------|
| **免费版** | ¥0 | 1 租户 · 5 用户 · 1 AI Agent · 基础模型 · 月配额 5 万 token · 沙盒关闭 |
| **Pro** | ¥30-60/席位/月 | 无限 Agent · 沙盒开启 · 知识库 · 审批 · 用量按 token 另计（成本 ×1.4） |
| **企业版** | ¥80-150/席位/月 或 打包 | SSO · 审计日志 · 专属模型（BYOK）· 白标 · 支持 SLA |

### 4.2 私有化定价锚点

| 规模 | 年授权费 | 实施费 |
|------|---------|--------|
| ≤200 用户 | ¥8-15 万 | ¥2-5 万 |
| 200-2000 | ¥20-50 万 | ¥5-15 万 |
| 2000+ | ¥60-100 万 | 定制 |

## 6. 实施路线图

```
Phase 1「能收钱」（4-6 周）→ G1+G2+G3
  交付：注册→免费试用→邀请同事→管理员手动开通 Pro→按配额计费
  验收：一个真实客户完整走通「注册→试用→付费→同事进场」

Phase 2「能签单」（6-10 周）→ G4+G5+G6+G7
  交付：企业采购必问项（BYOK/审批通知/审计/知识权限）
  验收：可回答 IT 采购问卷 80% 必查项

Phase 3「能续费」（持续）→ G8-G11
  交付：外部 IM 入口 + 场景模板 + ROI + 使用分析
  验收：月活跃率 > 40%、续费率 > 90% 目标

Phase 4「能签大单」（按需）→ G12-G15
  交付：License + 白标 + SSO + 管理 API
  验收：私有化交付文档完备（部署/迁移/升级手册）
```

## 8. 风险与对策

| 风险 | 对策 |
|------|------|
| 模型厂商降价/直销竞争 | 差异化在沙盒/审批/治理而非模型本身；BYOK 对冲 |
| 沙盒逃逸安全事故 | gVisor（`SANDBOX_RUNTIME=runsc` 已预留）；审计报告作为卖点 |
| 客户买了不用（留存差） | 场景模板 + 外部 IM 入口（用在工作流里而非新开网页） |
| 私有化交付重（实施成本高） | 部署文档化 + Docker Compose 一键 + 实施费覆盖 |
| 合规（数据出境/许可） | 私有化为主打 + 数据导出 + 审计日志 |

- agent-platform 是 weifuwu 的**完整消费方**——每次商业化功能开发（邀请/审计/计费）同时验证框架能力（email/队列/限流/中间件）
