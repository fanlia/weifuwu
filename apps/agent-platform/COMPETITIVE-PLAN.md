# agent-platform 核心竞争力计划（Competitive Plan）

> **状态**：✅ Phase 1 完成（C1 任务可靠性 + C2 风险分级，2026-12）——Phase 2（C3/C4）待做
> **定位**：模型不是壁垒（DeepSeek 谁都能调）——竞争力在模型之上的一层：
> **执行可靠 · 治理可控 · 记忆持续 · 质量可测 · 成本工程**。
> 前提：v4-flash 推理/代码/长上下文/便宜——我们的工作是把这些聪明变现为"客户可控的完成度"。
> 关联：COMMERCIAL-PLAN.md（功能层 ✅）/ COMMERCIAL-RISKS.md（质量层 ✅）——本计划是**竞争层**。

---

## 竞争力五层模型

```
┌──────────────────────────────────────────────┐
│ ⑤ 成本工程（模型路由/缓存/配额精度）           │
│ ④ 质量可测（反馈→评估→自评→看板）             │
│ ③ 记忆持续（工作空间/会话/知识库可信）          │
│ ② 治理可控（风险分级审批/策略引擎/审计）        │
│ ① 执行可靠（任务编排/自校验/失败恢复/断点续跑）  │
├──────────────────────────────────────────────┤
│ 模型层（v4-flash——人人可用，非壁垒）           │
└──────────────────────────────────────────────┘
```

**原则**：模型可换（BYOK 任意 OpenAI 兼容），五层能力不换——这是护城河。

## C1 执行可靠（最高优先——"AI 把事情做完"）

**现状**：agent 循环 + 沙盒工具（单轮）；多步任务无编排、失败即结束、无自校验。

**目标**：多步任务 = 计划 → 执行 → 自校验 → 汇报，失败自动恢复。

**方案**：
1. **任务工作流**（agent-runner 增强）：
   - 执行前让模型产出计划（steps）→ 逐步执行 → 每步后自校验（"这一步结果合理吗"）
   - 完成时结构化汇报：{ 做了什么 / 没做什么及原因 / 产物路径 / 需要的下一步 }
2. **失败恢复**：工具失败 → 模型决策（重试/换方案/放弃并说明）——而非直接结束
3. **断点续跑**：任务状态持久化（agent_logs/tasks 表）——沙盒销毁后长任务可恢复
4. **任务产物**：AI 产出文件/报告入工作空间（版本化已有基础）

**验收**：
- [x] 任务纪律提示：失败不放弃（换方案/明确说明）+ 结构化汇报（已完成/未完成/产物）——零额外调用
- [x] 自校验：runToResult 后模型自检（complete/missing JSON）→ 未完成追加标注（可配置关闭）
- [x] 失败恢复：框架 tool_result 回喂已有（模型下一轮决策）——纪律提示增强引导
- [x] 端到端：真实 DeepSeek 任务回复正常（纪律不破坏行为）+ 自校验链路无回归
- [ ] 断点续跑（长任务持久化——登记待做）

## C2 治理可控（风险分级审批——从"全批"到"分级批"）

**现状**：HITL 全量审批（每个操作都批）——安全但管理者疲劳放水。

**目标**：低风险自动执行、高风险才审批；审批卡片带 AI 推理摘要。

**方案**：
1. **风险分级**（agent 循环内）：模型对工具调用输出风险等级（low/medium/high）+ 理由——
   - low（读文件/检索）→ 自动执行
   - high（删除/写外部/命令执行）→ 审批（现状）
   - medium（写工作区/网络读）→ 策略决定（租户可配）
2. **策略引擎**：租户级策略（enterprise/agent 配置）："删除必须批 / 网络必须批 / 命令必须批"
   ——策略优先级高于模型自判（信任边界：模型判断是建议，策略是规则）
3. **审批摘要**：审批请求带模型理由（"为什么执行此操作"）——管理者 3 秒决策
4. **审批默认值**：策略未覆盖的 high 操作保持人工（默认安全，不放宽）

**验收**：
- [x] 框架 humanInTheLoop 支持函数（TDD +2：false 自动执行 / true 走审批——ai-agent.test 9 绿）
- [x] risk-policy.ts 规则引擎（high/medium/low 模式判定——纯规则零额外 LLM）
- [x] Agent 配置 risk_policy（auto 智能分级 / strict 严格）——Agent 详情下拉
- [x] agent-runner 按策略传条件审批函数（策略是规则，模型自判为未来增强）
- [x] 审批页高风险草稿提示（⚠️ 高风险操作）
- [ ] 模型自判风险（C2 增强——登记）

## C3 记忆持续（聪明模型的倍增器）

**现状**：会话内上下文有；跨会话/工作空间记忆无；RAG 基础检索。

**目标**：AI 越用越懂——工作空间索引 + 会话记忆 + 可信知识库。

**方案**：
1. **工作空间记忆**：Agent 首用/项目变化时扫描工作空间生成索引（README/结构/约定摘要）——
   每次任务前按需加载相关部分（上下文长不用全塞）
2. **会话记忆**：跨会话持久化（偏好/背景/最近决策）——messages/agents 表扩展或记忆文件
3. **知识库可信**：混合检索（向量+BM25）+ 引用溯源（答案标注来源文档）+ 无命中明确说
4. **记忆清理**：记忆可查看/清除（R10 合规联动）

**验收**：
- [ ] 新会话能引用上次会话背景（实测）
- [ ] 工作空间索引生效（AI 主动读相关文件而非全塞）
- [ ] 知识库回答带出处

## C4 质量可测（从被动反馈到主动评估）

**现状**：点赞/点踩 + 工具成功率（86%）——被动。

**目标**：评估集回归 + 模型自评 + 质量看板（销售证据）。

**方案**：
1. **评估集**：为场景模板（8 个）建评测用例（输入 → 期望行为）——prompt/工具改动跑回归
   （v4-flash 便宜——低成本批量评估）
2. **模型自评**：AI 完成任务后自检（是否满足目标/有无幻觉风险）——低置信不下发或标注
3. **质量看板**：每 Agent 质量分（成功率/反馈率/采纳率/自评置信）——owner 与客户成功共用
4. **质量导出**：评估报告 CSV（R6 反馈数据 + C4 指标——续费谈判证据）

**验收**：
- [ ] 评估集跑通（改 prompt 前红/后绿）
- [ ] 自评低置信 → 标注或人工介入
- [ ] 质量看板/导出可用

## C5 成本工程（便宜要用对）

**现状**：计量/配额/ROI 精确——无模型路由/缓存。

**目标**：简单任务小模型、高频问答缓存、成本告警。

**方案**：
1. **模型路由**：按任务复杂度路由（摘要/分类/检索 → 小模型；推理/代码/多步 → v4-flash）
   ——Agent 可配主模型 + 轻量模型
2. **答案缓存**：知识库高频问答命中缓存（相同 query + 相同知识库版本）
3. **成本告警**：租户配额 80% 提醒（邮件——复用 G5 通道）+ 超限加购提示
4. **成本明细**：按 Agent/场景的成本拆分视图（回复/KB/Webhook——R3 场景维度已有）

**验收**：
- [ ] 路由生效（简单任务 token 成本下降实测）
- [ ] 缓存命中率统计
- [ ] 80% 告警邮件实测

## C6 执行生态（沙盒变工具箱——网络效应）

**现状**：文件工具 + bash + 技能（内置几个）；技能无市场。

**目标**：技能库扩充 + 工具按租户授权 + 技能贡献闭环。

**方案**：
1. **技能库扩充**：内置技能补高频（数据库查询/HTTP 请求/表格处理/文档生成）——按消费方需求驱动
2. **工具授权**：租户级工具白名单（谁能用数据库工具）——权限矩阵扩展
3. **技能市场雏形**：技能目录（启用/评分）+ 自定义技能已有基础（skills 目录）
4. **技能质量**：技能随 C4 评估集回归

**验收**：
- [ ] 新增 5+ 高频技能（消费方缺口驱动）
- [ ] 租户工具授权生效
- [ ] 自定义技能可评分/搜索

## 路线图

```
Phase 1「任务与治理」（4-6 周）→ C1 + C2
  交付：多步任务可靠 + 风险分级审批 + 策略引擎 + 审批摘要
  验收：任务完成率提升（失败恢复）+ 审批量下降（分级）而安全不降

Phase 2「记忆与质量」（6-8 周）→ C3 + C4
  交付：工作空间/会话记忆 + 评估集 + 自评 + 质量看板
  验收：跨会话连续性 + prompt 改动回归可测

Phase 3「成本与生态」（持续）→ C5 + C6
  交付：模型路由 + 缓存 + 技能库 + 工具授权
  验收：token 成本下降 + 技能使用率
```

## 关键指标

| 指标 | 现在 | 目标 |
|------|------|------|
| 多步任务完成率 | 无编排（失败即结束） | > 70%（自校验+恢复） |
| 审批打扰率（每 10 次 AI 操作需审批数） | 全量（10/10） | < 3/10（风险分级） |
| 工具成功率 | 86% | > 92%（恢复+自评） |
| 跨会话记忆可用 | 无 | 新会话可引用旧背景 |
| 简单任务成本 | 统一模型 | -40%（路由） |
| 知识库回答出处率 | 部分 | 100%（可溯源） |

## 依赖与风险

| 依赖 | 风险 | 对策 |
|------|------|------|
| 模型自判风险等级 | 误判（低风险判高=烦；高判低=险） | **策略引擎优先**——规则是边界，模型是建议 |
| 评估集建设 | 用例质量影响回归有效性 | 从 2 个模板起步，消费方真实任务沉淀 |
| 记忆持久化 | 数据量/隐私 | 记忆可查看可清除（R10 联动）+ 按 Agent 隔离 |
| 任务编排复杂度 | 引入不稳定 | 增量演进（先自校验/恢复，再断点续跑） |
