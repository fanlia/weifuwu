# agent-platform 销售手册（Sales Playbook）

> **状态**：2026-12 建立——基于最终能力（G1-G15 功能层 + R1-R11 风险层 + C1-C6 竞争层）
> **定位一句话**：让员工"指挥 AI 干活"——每一步有纪律、有分寸、有记忆、有质量、有成本、有工具，背后有审计/合规/私有化兜底。

---

## 0. 目标客户与入口

| 客户 | 场景 | 入口能力 |
|------|------|---------|
| SMB（10-200） | 1+2 | 注册免费试用（14 天）→ 邀请同事 → 群聊 |
| 中型（200-2000） | 2+3+4 | 沙盒 + 分级审批 + ROI |
| 金融/医疗/政务 | 5 | 私有化 + SSO + 审计 + 威胁模型 |
| 集团/平台 | 6 | 企业-子租户 + 统一结算 |

**demo 环境**：`node --env-file=.env scripts/seed.mjs`——多角色账号（老板/员工/管理员/双租户/审批待办/知识库/技能）。

---

## 1. 企业知识库问答

**画像**：全员型组织，制度/FAQ/产品资料散落。
**工作流**：管理员建知识库 Agent（上传文档自动分块向量化）→ 员工群里 @检索（带出处）→ 外部 IM 群机器人同步可用 → 差评反馈进质量卡 → 运营优化文档。
**销售话术**："新人培训期缩短 30%——答案带出处，员工信；差评可见，运营能改。"
**demo 路径**：登录 admin → Agent 详情（产品知识库）→ 技术部聊天 @产品知识库 → 提问 → 看带出处回答 → 点赞/点踩 → 质量卡。
**验收指标**：检索命中率 >70% · 差评率 <15% · 周活跃提问数（>20 条/百人）。

## 2. AI 数字员工

**画像**：人力密集型（财务/运营/数据岗），"让 AI 干活"。
**工作流**：建数据助手（文件+命令工具，沙盒隔离）→ 群里下达任务 → AI 多步执行（read_csv 等技能）→ 失败自动换方案 → 高风险操作分级审批（读自动/删审批）→ 结果结构化汇报 → 老板看 ROI。
**销售话术**："AI 替你干重复活，沙盒里干，每一步可批可查——ROI 每周算给你看。"
**demo 路径**：@小码 "用 read_csv 分析 sales.csv"（工作空间预置文件）→ 看工具调用/自校验/汇报 → 审批页看分级（低风险自动、高风险待批）。
**验收指标**：多步任务完成率 >70% · 审批打扰率 <3/10 次操作 · 工具成功率 >92% · ROI 节省 > 成本。

## 3. 研发辅助

**画像**：软件团队，代码不出域、命令可控。
**工作流**：开发助手（代码模板+沙盒+版本管理）→ AI 读/改/跑测试 → 危险命令审批（带推理摘要）→ BYOK 公司模型 → 记忆项目约定。
**销售话术**："代码留在你机房，模型用你的 Key，AI 记得你们的技术栈。"
**demo 路径**：Agent 详情（开发助手模板 4 技能）→ 单聊"帮我修复这段代码" → 工作空间版本回滚 → BYOK 配置页。
**验收指标**：工具成功率 >90% · 代码任务完成率 · 沙盒零逃逸事件。

## 4. 业务自动化（Webhook）

**画像**：客服/运维/电商，工单/告警流。
**工作流**：Webhook Agent（HMAC 签名）→ 外部 POST → AI 多步处理（分类/查询/答复）→ 高风险审批 → 回推 → 计量配额。
**销售话术**："7×24 自动响应，签名验真，配额锁死——成本不失控。"
**demo 路径**：通知机器人 Webhook 端点 + 签名示例 → curl 模拟工单 → 看处理与回推 → 配额 80% 告警邮件。
**验收指标**：响应时间 <30s · 自动处理率 >60% · 人工介入率 <40%。

## 5. 合规敏感行业（金融/医疗/政务）

**画像**：审计留痕、数据不出域、身份受控。
**工作流**：私有化部署（Compose 一键）→ License + 白标 → SSO（OIDC）→ 分级审批 + 审计导出 → 数据导出/删除（GDPR）→ 威胁模型文档交审。
**销售话术**："采购问卷必查项全绿——私有化、SSO、审计、删除、权限矩阵、威胁模型，一份文档交完。"
**demo 路径**：部署文档（docs/deployment.md）→ 合规文档（docs/compliance.md）→ 威胁模型（docs/sandbox-threat-model.md）→ 管理后台（租户/计划/停用）。
**验收指标**：采购问卷 80% 必查项可答 · 审计导出完整性 · 删除级联正确性。

## 6. 集团/平台运营

**画像**：集团/连锁/平台，多事业部隔离但统一付费。
**工作流**：管理员建企业账户 → 挂入子租户（各自隔离）→ 企业聚合用量统一结算 → 子租户独立配置 → 平台看板。
**销售话术**："一个平台管所有事业部，各自隔离，统一算账。"
**demo 路径**：/admin 企业卡片（建企业 → 挂 demo/acme 子租户 → 聚合用量）→ 平台概览（活跃/成本）。
**验收指标**：企业聚合正确性 · 子租户隔离零泄漏 · 结算对账一致性。

## 2. 销售流程（漏斗）

```
① 演示（30 分钟）→ 用 seed 场景 1+2 讲「群里指挥 AI 干活」
② 试用（14 天）→ 免费版：5 成员/5 万 token/沙盒——重点给「分级审批 + 记忆 + 质量卡」体验
③ 转化 Pro → 线下付费 → 管理员开通（配额 100 万）
④ 大客户 → 私有化评估 → 交付三件套（部署/升级/运维文档）→ License + 白标
⑤ 续费 → ROI 报告 + 质量看板 + 使用分析（谁在用/用多少/质量如何）
```

## 3. 关键指标（客户成功共用）

| 维度 | 指标 | 目标 |
|------|------|------|
| 激活 | 注册→建 Agent 转化 | >50% |
| 使用 | 每 Agent 周消息数 | >15 |
| 质量 | 工具成功率 / 差评率 | >92% / <15% |
| 价值 | ROI 节省/成本 | >1.5× |
| 留存 | 月活跃率 | >40% |
| 治理 | 审批打扰率 | <3/10 |
