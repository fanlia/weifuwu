# 模拟数据收集（问卷）——客户使用指南

> **用途**：10 个不同人设的 AI 角色，真实浏览器填写问卷并提交（模拟数据收集）。
> 适用场景：问卷测试、多角色预填、UAT 模拟、内部调研演练（**非真实调研——AI 身份可标注**）。

---

## 一、启动环境

| 项 | 说明 |
|----|------|
| 平台 | `http://localhost:3000`（admin@demo.com / admin123） |
| 问卷填写页 | `http://localhost:3000/demo-survey`（人可看/填；AI 从容器内访问 `http://host.docker.internal:3000/demo-survey`） |
| 统计页 | `http://localhost:3000/demo-survey/stats`（实时：在线人数/答题进度/答题流/提交明细） |
| 沙盒镜像 | `SANDBOX_IMAGE=ap-sandbox:latest`（含 chromium + agent-browser——AI 填表的基础） |

## 二、初始化（一次，~2 秒）

```bash
cd apps/agent-platform
node --env-file=.env scripts/seed-survey-agents.mjs
```

自动完成：
1. 建「模拟调研组」部门
2. 建 10 个角色 AI（财务小王/市场小李/产品老张/客服小陈/研发大刘/人事小周/销售阿强/运营小赵/行政陈姐/实习生阿泽——人设各异）
3. 全部拉进部门（含网络权限——浏览器填写必需）

> 改人设/加角色：编辑脚本里 `PERSONAS` 数组（一行一个角色）。

## 三、日常使用（三种方式）

### 方式 1：一键派单（最推荐——demo 现场用）

打开统计页 → 点「🚀 一键 10 角色填写」→ 10 个角色错峰开始填：

```
统计页实时看到：
  在线人数跳动（0→1→5→10）
  填写进度条逐个推进（财务小王 1/5 → 2/5 ...）
  实时答题流滚动（每题同步）
  提交逐个锁定（计数 +1 跳动动画）
```

### 方式 2：手动 @ 定向派单

平台 → 模拟调研组 → 群里发（**记得加"完成后关闭浏览器页面"**——否则统计页一直显示在线）：
```
@财务小王 请填写 http://host.docker.internal:3000/demo-survey?s=财务小王 问卷并提交（完成后执行 agent-browser close 关闭页面）
```
支持任意组合（1 个/几个/全部角色）。

### 方式 3：人工填写

浏览器直接打开 `http://localhost:3000/demo-survey`——每完成一题实时同步到统计页，提交后锁定。

## 四、统计页看什么

| 卡片/面板 | 内容 |
|----------|------|
| 已提交（锁定） | 提交份数（+1 跳动动画） |
| 在线 | 当前正在填写的角色（重连去重 + 僵尸清理防虚高） |
| 填写中的来源 | 正在答题的角色数 |
| 已同步的答题数 | 逐题同步累计 |
| 填写进度 | 每个角色 5 题进度点（●●●○○ 3/5） |
| 实时答题流 | 每题答案滚动（淡入动画） |
| 已提交明细 | 来源/时间/行业/年龄/评分/关注/反馈 |

## 五、换问卷（"后续填写其它文件"）

问卷页是纯静态页面（`public/survey-form.html`——CDN 模式，weifuwu 组件 + 原生表单控件）：

1. **改题型**：编辑 `public/survey-form.html` 的题目区（label/name/选项）——**name 保持与统计页 Questions 数组一致**（进度点按题数）
2. **改页面上限**：统计页 `QUESTIONS` 数组（题目列表）同步
3. **完全换页**：替换 `public/survey-form.html` 内容——WS 协议不变（`survey:answer`/`survey:submit`/`survey:hello`）——统计页零改动
4. **外部表单页**：任意页面只要接入同一 WS 协议（`/survey-live`）即可联动

## 六、注意事项

- **提交即锁定**：提交后表单禁用（"✅ 已提交——不可修改"）——协议层面服务端只记提交结果，重复提交以第一次为准
- **不落库**：数据在内存（最近 20 条）——服务重启清零；需要持久化可把 `survey:submit` 处理改为写文件/DB
- **在线人数**：统计页本身不计入在线（只订阅不发 hello）；带 `?s=` 的身份唯一
- **AI 填写需网络权限**：角色 Agent 必须 `allow_network=true`（seed 已配）；容器通过 `host.docker.internal` 访问宿主页面
- **合规**：模拟数据收集场景标注"AI 生成"；不得用于刷真实调研/投票（数据欺诈红线）

## 七、常见问题

| 问题 | 处理 |
|------|------|
| AI 不填/没反应 | 检查 SANDBOX_IMAGE 就绪（healthz）、角色 allow_network、部门存在 |
| 在线人数虚高 | 已修（重连去重 + 僵尸清理）——仍异常看是否多实例/多容器 |
| 统计页连接不上 | 确认 `/survey-live` WS 可连（浏览器 console 看 ws 错误） |
| 提交没计数 | 必填项缺失会被页面拦截（年龄/行业/满意度）——AI 需填全 |
