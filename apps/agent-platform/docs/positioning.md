# 竞争定位与销售叙事（R11）— 收窄到能赢的战场

> **状态**：2026-12 建立——主叙事 + 差异表（销售一页纸基础）

## 主叙事（一句话）

> **给"需要 AI 干活但必须可控可审计"的企业——私有化部署的 AI Agent 平台：沙盒安全执行 + 人工审批闸门 + 数据自主。**

## 不做（诚实）

- ❌ 不做 C 端聊天/通用对话——大厂免费碾压
- ❌ 不做无代码工作流/Agent Builder（Coze/扣子主场）——工程投入大
- ❌ 不做模型（无自研模型优势）

## 差异化战场（我们赢的三把刀）

| 刀 | 能力 | 谁在乎 | vs 大厂 |
|----|------|--------|---------|
| **沙盒执行** | AI 真的读写文件/跑命令，Docker 隔离 + 威胁模型 | IT/合规 | 钉钉 AI 不能碰文件；我们敢 |
| **审批治理** | HITL 每步可批 + 审计导出 + 角色权限 | 管理者/法务 | 大厂对话无审批概念 |
| **私有化+数据自主** | 客户机房部署 + BYOK + 白标 + License | 金融/政务/大企业 | 大厂 SaaS 数据出境问题 |

## 差异表（销售对照）

| 维度 | agent-platform | 钉钉 AI/飞书智能伙伴 | Coze/扣子 | 直接 API + 自建 |
|------|---------------|---------------------|-----------|----------------|
| 部署 | 私有化/自托管 | SaaS | SaaS | 自研成本 |
| 沙盒执行 | ✅ Docker 隔离 | ❌ 无 | 部分（云端） | 自建高风险 |
| 审批 HITL | ✅ 内建 | ❌ | ❌ | 自建 |
| 多租户治理 | ✅ 内建 | 组织内 | ❌ | 自建 |
| 审计导出 | ✅ CSV/API | 部分 | ❌ | 自建 |
| 数据自主 | ✅ BYOK/私有化 | ❌ | ❌ | ✅ |
| 模型选择 | ✅ BYOK 任意 OpenAI 兼容 | 厂商限定 | 多模型 | ✅ |
| 上手成本 | 中（要部署） | 零 | 零 | 高 |

**结论**：SMB 免费市场让给大厂；**能赢的战场 = 需要沙盒执行 + 审批治理 + 数据自主的中大型/行业客户**（金融/政务/制造/研发密集型）。

## 场景聚焦（做深两个最能打场景）

1. **S1 企业知识库 + 全员问答**（场景 1）——补：外部 IM 入口（G8 已打底）+ 知识权限（G7 已打底）→ 深化 RAG 质量
2. **S3 研发辅助**（沙盒代码执行）——沙盒 + 审批是天然组合 → 深化工作空间/版本管理
