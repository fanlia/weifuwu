## 0. 现有功能地图（审视基线）

```
认证      登录 / 注册（限流）/ 个人设置
多租户    公司 / 部门 / 成员管理（tenantId 隔离）
Agent     ai / user / webhook / knowledge_base 四类 + 内置工具 + 角色模板 + 技能（热重载）
对话      流式 AI + HITL 审批 + 工具卡片 + 消息搜索/编辑/撤回 + Markdown + token 用量 + 重试 + WS 断连提示
知识库    embedding + pgvector 检索 / 上传 / 重索引
沙盒      Docker 容器池（心跳/池上限/LRU/网络隔离）+ 工作空间文件浏览器
Webhook  收发 + 签名验证 + 重试 + 日志
统计      Dashboard（Agent/消息/漏斗）+ token 成本 + Agent 日志 + 激活漏斗埋点
```

## 1. 老板视角（商业价值 / 成本 / 增长）

| 关注点 | 现状 | 问题 | 优化（优先级） |
|---|---|---|---|
| 成本 | token 用量统计 | 只展示、无预算/预警 | **P1 成本控制**：agent 级 token 配额/预算 + 超限告警（webhook/通知） |
| 增长 | 激活漏斗（注册→建Agent→发消息） | 漏斗止于"发消息"，无留存/活跃 | **P1 业务大盘**：DAU/留存/活跃 Agent 数/会话数趋势 |
| 收入 | 无计费 | 多租户 SaaS 无变现能力 | **P2 计费**：套餐/用量计量/配额（先做配额后做账单） |
| 竞争 | 平台定位 | 无差异化卖点呈现 | **P2 案例/模板**：成功案例页、一键模板（复用 role-templates） |

**一句话**：先补"成本可控 + 增长可看"，再做"计费变现"。

## 2. 用户视角（好用 / 快 / 不出错 / 隐私）

| 关注点 | 现状 | 问题 | 优化（优先级） |
|---|---|---|---|
| 对话体验 | 流式 + Markdown + 工具卡片 | 长回复定位困难；无对话导出 | **P1 对话导出**（Markdown/文本）+ **回复内锚点/标题目录**（Markdown 长文导航） |
| 移动端 | 桌面布局 | 14 页 SPA 未适配移动 | **P1 响应式**：关键页（Chat/Approvals）移动优先 |
| 隐私 | 租户隔离 | 无"对话数据可见性"说明 | **P2 隐私页**：数据存储/隔离/沙盒边界透明化（信任建设） |
| 操作效率 | 快捷键（Ctrl+Enter 发送） | 无全局快捷入口 | **P2 快捷键**：⌘K 快速跳转（Agent/部门）、Esc 关闭弹层统一 |
| 容错 | 重试 + 断连提示 | 重试后上下文可能丢失 | **P1 重试保上下文**：重试携带完整历史（验证当前实现） |

**一句话**：对话导出 + 移动适配是用户最直接的获得感。

## 3. 产品经理视角（功能完整性 / 用户旅程）

| 旅程阶段 | 现状 | 缺口 | 优化（优先级） |
|---|---|---|---|
| 发现 | role-templates 列表 | 无模板市场/筛选/预览沉浸 | **P1 模板市场页**：分类 + 预览（agent/:id/preview 已有 API） |
| 创建 | NewAgent 表单 | 创建后无引导（知识库/技能/工作空间） | **P1 新手引导**：AgentDetail 空态引导（"先加知识库/再对话"） |
| 调试 | AgentDetail 编辑 | 无 Prompt 调试台（改系统提示→立即试） | **P2 调试工作台**：右侧系统提示编辑 + 内嵌对话试跑 |
| 使用 | Chat | 无多 Agent 协作/编排 | **P2 多 Agent**：Agent A 调 Agent B（工具化调用） |
| 维护 | 无版本 | 系统提示改动不可回滚 | **P2 版本管理**：Agent 配置快照/发布/回滚 |
| 分析 | token 日志 | 无对话质量评估 | **P2 满意度**：回复点赞/点踩 + 反馈入库 |

**一句话**：模板市场 + 新手引导是激活率关键；版本管理是多租户生产化的必需。

## 6. 计划设计师视角（信息架构 / 任务流 / 效率）

| 关注点 | 现状 | 问题 | 优化（优先级） |
|---|---|---|---|
| 信息架构 | 侧边栏 14 页平铺 | 层级扁平，Agent 相关散落 | **P1 IA 重构**：侧边栏分组（工作台/管理/设置）+ AgentDetail 内 Tab（配置/对话/知识库/日志/工作空间） |

| 关注点 | 现状 | 问题 | 优化（优先级） |
|---|---|---|---|

**Wave 6 发现并规避的框架级问题**（应后续在框架层根治）：
- **路由页面组件（AppLayout 内）的 rerender（ctx.ui.render / store.set→useExternal）不落地 DOM**
  ——Templates 首次用「工厂异步 rerender」多次失败（store.state 已更新但渲染空）；
  改用 **§3.3 工厂层 await 数据**（首次渲染即带数据）绕过。Agents 页侥幸未暴露
  （/api/agents 响应快于首次渲染）。**建议框架层排查 renderOne 对路由页面组件的 patch**。

**验证标准**：每项按框架纪律——真实浏览器验收（agent-browser）+ DOM 级测试（仿 Editor.dom.test 模式）+ 全量回归。
