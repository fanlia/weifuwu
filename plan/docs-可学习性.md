> 一句话目标：**weifuwu 包本身的「找得到/学得会/读得懂」**——docs 动线示例
> （新开发者 30 行全栈跑起来）+ 后端 API 速查表（主导出 ~40 个——有索引
> 不靠搜源码）+ CHANGELOG 分类聚合（137 条平铺 Other → 按域分组——变更
> 可检索）。

> 时候」，缺「**找到 API 的路径、第一次跑起来的动线、变更的可检索性**」。

> 单表）· 无从零动线示例（platform server.ts 350 行是唯一参考）·
> CHANGELOG [0.91.0] 158 行平铺（Other 组 137 条——升级者找不到「我关心
> 的变更」）。
> **范围界定**：只动 weifuwu 包的交付物（docs/CHANGELOG 生成逻辑）——
> **不碰脚手架/项目模板**（判负——单项目无通用沉淀·用户拍板目标=weifuwu
> 本身）。
