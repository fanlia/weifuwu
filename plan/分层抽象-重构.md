> 架构定案（2027-09）：**三层各上浮为可生成的抽象**——行为契约 hooks · 组件抽象 ·
> 布局原语——组件从「目录清单」变「抽象实例」。开发者三用法（用现成/换皮/拓场景）

## 波次计划

### W1 —— vdom 原语二件（signal · 轻量组件形态）

1. **signal 状态原语**：`ctx.ui.signal<T>(init) → { get, set }`——setter 自动重渲染
   （消灭手动 `ctx.render()`——Observable 基座已有——getter/setter 语法糖）
   · 契约：set 触发渲染 · get 最新 · 跨渲染保持（mount 闭包）
2. **轻量组件形态**：Component 返回 VNode/数组 = 纯函数组件（内核识别——免两阶段）
   · 契约：纯函数组件 mount（工厂语义垫平——有状态判定保持）
3. 验收：契约 +8 · 老组件零改动（tsc 0 · 契约 460 全绿）

### W2 —— useOverlay 行为契约（弹层四件套单源）

1. **内核原语补位**：focusTrap（Tab 循环 + 失焦恢复）· scrollLock（body 锁）·
   restoreFocus（关闭回触发元素）——现弹层组件手搓面的内核化
2. **useOverlay 契约**：`useOverlay({ open, onOpenChange, role: 'dialog', trapFocus })`
   → `{ maskProps, panelProps, close }`（Esc · aria-modal · 层级 · 焦点全内建）
3. **Modal 首个消费者**（行为等价重构——手搓面删除走契约）
4. 验收：useOverlay 契约 +6 · Modal 重构后**行为等价**（契约 + 场景弹窗测试 +
   a11y 审计 0 违规 · 展示 demo 零差异）——契约 460+ 全绿

### W3 —— createComponent 组件抽象（骨架生成）

1. **createComponent 抽象**：`{ name, role, behaviors, states, parts }`——
   · 状态类自动（`wf-x--<state>`）· aria 角色映射表（switch→checked · tab→selected ·
   dialog→modal）· 焦点面（tabIndex/Enter/Space/方向键按角色）· 结构渲染
2. **首批验证**：Badge / Switch 重构为声明（生成类与现类逐属性 diff 等价）
3. 验收：createComponent 契约 +8 · Badge/Switch 视觉等价（契约 + showcase 测试回归）
   · 生成器输出 = 现 CSS 手写类（diff 0）

### W4 —— layout 原语抽象（defineLayout + 生成器）

1. **defineLayout 声明**（构建期——规则唯一手写面）：space 标尺 · 结构原语
   （stack/row/container/panel/toolbar——**组合缺省内建**）· 断点变体（声明 bp 即有）
2. **生成器**：声明 → 类（`wf-stack` 自带 gap · `wf-hidden@lg` 自动生成……）
3. **等价验收**：生成结果 vs 现 174 类**逐属性 diff 等价**（layout-inventory 审计
   改核对声明——D12 演进）· 视觉回归（layout-semantics 场景全绿）
4. 验收：layout-inventory 改声明核对 · 生成 diff 0 · 布局场景全绿

### W5 —— 家族推进（useField · useCombobox · createOverlay）

1. **useField + Field 原语**：label/required/error aria/hint 单源——Input/Select
   消费（props 回归瘦身——老 props 保留渐进）
2. **useCombobox**：选项/搜索/键盘导航——Select/Cascader 消费
3. **createOverlay 家族化**：Drawer/ActionSheet 重构（同 W2 契约——家族工厂）
4. 验收：契约 +12 · 家族行为等价（showcase 交互测试回归）· a11y 审计 0

### W6 —— 出口与文档（双形态开放）

1. **子路径导出**：`weifuwu/hooks`（契约 + 原子）· `weifuwu/layout`（defineLayout + extend）·
   `weifuwu/components`（组件 + createComponent/createOverlay）
2. **docs 双形态**：每个家族页「用组件 / 用契约 / 用原语」三示例——
   开发者三用法文档化（§5.11 双形态 · layout 原语文档）
3. **showcase 扩展演示**：换皮示例（useOverlay + 自绘皮）· 自定义原语示例（extend）
4. 验收：子路径导入可解析（tsc/构建）· docs 结构完整 · showcase 演示可交互

### W7 —— 全量回归 + 发布 + 归档

1. 全量门：契约（+34 线）· 场景 · showcase（+演示）· server · 平台 492 ·

## 风险与兼容登记

| 风险 | 对策 |
| --- | --- |
| Modal/Drawer 重构行为分叉 | **先契约再重构**（W2 契约先行）· 行为等价 = 契约+场景+showcase 三线 |
| CSS 生成器输出漂移 | 逐属性 diff 等价（W4 硬验收）· 不达标 = 修生成器不修手写 |
| 抽象过度（配置地狱） | 判据：声明比实现短且机械部分全消失——W3/W4 每波验收含「声明/实现长度比」 |
| 存量 138 组件行为回归 | **存量零改动**（仅新增抽象 + 少数消费组件渐进）——每波契约全量回归门 |
| signal 语义与 ctx.render() 并存 | signal 是**增量原语**（不取代 render）——更新纪律：新组件/维护用 signal |
