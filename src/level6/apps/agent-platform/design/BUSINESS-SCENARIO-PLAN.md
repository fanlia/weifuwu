## 3. 波次（每波独立可验收）

### W0 · 白盒基线（前置门）
- agent-browser 走六条旅程快乐路径（每场景一条：注册→建→用→看结果）
- 旅程缺口即时定级 P0/P1/P2（探针修正本清单——**缺口重定位纪律**——现缺口是静态证据，走查可能 解决/加重）
- 每条旅程补 1 个 UI 冒烟测试（沿用 test/ui 基建）——**验收：六旅程走通 + 六冒烟入套件**

### W1 · G-A 冷启动样板（场景 1）
- 注册后一键「创建演示空间」：部门 + 客服 agent + 知识库（FAQ 种子）+ 经理（三选一确认式）
- **验收**：新租户 ≤3 步见到第一条 AI 回复（UI 测试——红→绿）；含 G-B 走查结论（试用触达不足则同波修复）

### W2 · G-G 问卷 UX（场景 5）
- 问卷发起页（选角色/成员/问题 + 派发）+ 进度/结果视图（部门空间 + 完成率）

### W3 · G-F 编排交互面（场景 4）

### W4 · G-C IM 接线向导（场景 2）

## 4. 判负登记

| 候选 | 判负原因 | 翻案条件 |
|---|---|---|
| 交付物全格式 Web 预览（pptx/docx/xlsx 渲染） | 浏览器端渲染成本高——文本预览 + 下载已覆盖核心 | 客户明确要求在线编辑类场景 |
| 编排可视化 DAG 画布 | 属低代码平台范畴——平台边界声明（非万能框架） | 客户合同级需求 |
| 问卷 C 端 H5 投票页 | 超出当前形态（企业内应用 + 邮件通知已够） | 外部受访者场景立项 |
| 场景 6 多镜像分发（sandbox 镜像仓库） | 无交付证据——单机 compose 已够当前客户 | 出现多机部署客户 |
