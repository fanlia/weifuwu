# 定价模型（R8）— BYOK 与订阅的商业逻辑

> **状态**：2026-12 建立——定价逻辑文档化（含 BYOK 矛盾解法）

## 核心矛盾

BYOK（企业自带模型 Key）→ 平台不赚模型差价 → 收入模式被削弱。
**解法**：收入分两条腿——**功能费（席位）** 与 **用量费（模型代购）**——BYOK 客户走功能费，代购客户走用量费。

## 定价结构

```
┌──────────────────────────────────────────────────────┐
│ ① 功能费（所有客户）                                    │
│    席位订阅：按启用成员数 × 月（免费版 5 席上限）          │
│    平台能力：Agent 数/知识库容量/审计保留期（按档）        │
├──────────────────────────────────────────────────────┤
│ ② 用量费（模型代购客户）                                 │
│    token 计量（agent_logs 全场景——R3 已收口）           │
│    单价 = 模型成本 × 1.3-1.5（毛利）                    │
│    免费版 5 万 token/月 · Pro 100 万/月（超限拦截或加购）  │
├──────────────────────────────────────────────────────┤
│ ③ 私有化（大客户）                                      │
│    年授权费（席位/并发规模档）+ 实施费 + 年度维护 15-20%    │
│    BYOK 必配（模型自主）+ 白标 + SSO 含在授权内           │
└──────────────────────────────────────────────────────┘
```

## 计费模式区分（管理后台/租户标记）

| 模式 | 判定 | 收入来源 | 平台承担 |
|------|------|---------|---------|
| **代购** | 租户未配 BYOK（用平台 Key） | 席位 + token 加价 | 模型 API 成本 |
| **BYOK** | 租户配了自己的 Key（Settings 模型配置） | 仅席位 | 无模型成本 |

管理后台（/admin）租户列表按此标记——运营一眼区分收入类型。

## 档位锚点

| 档 | 价格锚点 | 功能 | 用量 |
|----|---------|------|------|
| 免费版 | ¥0 | 1 租户 · 5 成员 · 基础 Agent | 5 万 token/月 |
| Pro | ¥30-60/席/月 | 无限 Agent · 沙盒 · 审批 · 知识库 | 100 万 token/月（超限加购） |
| 企业版 | ¥80-150/席/月 | SSO · 审计导出 · BYOK · 白标 | 按量 |
| 私有化 | ¥8-100 万/年（规模档） | 全部 + 部署/升级/维护 | 按量/包年 |
