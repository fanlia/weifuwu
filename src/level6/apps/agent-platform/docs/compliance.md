# 数据合规说明（R10）

> **状态**：2026-12——导出/删除已实施；隐私政策模板待产品化

## 数据清单与处理

| 数据 | 存储 | 保留策略 | 删除行为 |
|------|------|---------|---------|
| 账号资料（_weifuwu_users） | 平台库 | 账号存续期 | 匿名化（email→deleted-{id}@deleted.local，name→已删除用户，密码失效） |
| 成员关系（_weifuwu_app_members） | 平台库 | 账号存续期 | 删除 |
| 会话（_weifuwu_sessions） | 平台库 | refresh 轮换 | 删除（登录立即失效） |
| 消息（messages） | 业务库 | 业务存续期 | **保留**（团队业务数据）——sender Agent 匿名化（名→已删除用户） |
| 执行日志（agent_logs） | 业务库 | 业务存续期 | **保留**（用量/计费审计）——不关联个人身份 |
| 审计日志（audit_logs） | 业务库 | 合规存续期 | **保留**（只读审计，去用户显示名） |
| 知识库文档（kb_*） | 业务库 | 租户存续期 | 租户删除时清理 |

## 用户权利（GDPR 对应）

| 权利 | 实现 |
|------|------|
| 数据可携带（导出） | `GET /api/auth/export`——资料/成员关系/Agent/消息 JSON 下载（Settings → 数据与账号 → 导出） |
| 被遗忘权（删除） | `DELETE /api/auth/account`——身份匿名化 + 会话清除 + 成员关系移除（Settings → 删除账号，confirm 确认） |
| 更正 | `PUT /api/auth/profile`（姓名） |

## 已知边界（诚实登记）

1. **Access token 残余有效**：JWT 无状态——删除后已签发的 access token 在 TTL 内（默认 30 分钟）仍可访问；refresh token 已删（刷新即失效）。缓解：短 TTL + 登录失效提示。
2. **消息内容保留**：团队对话是**业务数据**（删除者不是唯一利益方）——按 GDPR"业务必要"保留；个人身份已匿名。
3. **审计日志保留**：合规不可删除（防删除掩盖操作）——仅去显示名。
4. **平台管理员数据**（ADMIN_EMAILS）：管理员账号删除同流程（匿名化）。

## 部署侧建议

- 数据存储位置：私有化 = 客户机房（数据不出域）——合规卖点
- 保留期策略：按客户合规要求配置（当前保留 = 业务存续期；可加 retention 配置登记待做）
- 隐私政策/数据处理协议（DPA）：模板待法务/产品化（登记）

## 验证记录

- 导出：资料/成员/Agent/消息 JSON 完整 ✓
- 删除：账号匿名化 ✓ 旧邮箱无法登录 ✓ 原 refresh 失效 ✓ 成员关系移除 ✓
- 消息历史保留且 sender 匿名 ✓（agent 名 → 已删除用户）
