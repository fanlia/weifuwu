# 30 分钟 Demo 脚本（销售执行）——「群里指挥 AI 干活」

> **状态**：2026-12 · 配合 sales-playbook 场景 1+2 · 目标：让客户在 30 分钟内看到
> "AI 是群成员"的完整体验 + 治理/安全兜底，产生"我要试用"的冲动。
> **演示环境**：seed 多角色账号（admin@demo.com/admin123）· 技术部群（张明/李华/小悟/小码）

---

## 准备（2 分钟）

1. 打开平台 → 登录 admin@demo.com
2. 进入技术部群（成员：张明/李华 真人 + 小悟/小码 AI）
3. 打开 Agent 列表：小码（角色标签"通用开发助手·代码/脚本/数据分析"）
4. 话术："这个群里有 2 个人、2 个 AI——接下来的演示，你们可以猜哪句话是 AI 说的"

## 第一幕：群成员认知（3 分钟）——AI 知道群里都有谁

- 发消息：`@小码 这个群里都有谁？各自是做什么的？`
- 小码回答：张明（人·管理员）+ 小码（代码/脚本/数据分析）——**角色标签 + 专长**
- 话术："AI 知道自己是谁、群里还有谁——这是分工的前提。人 @ 他就干活，不用教"

## 第二幕：知识库问答（5 分钟）——答案带出处

- 发消息：`@产品知识库 报销流程是什么？`
- 回答带知识库出处
- 点赞 👍 → 话术："回答好坏员工说了算——差评进质量卡，运营改文档，形成闭环"
- （可选）钉钉群机器人演示：外部 IM 群里 @机器人 同样问题 → 平台回显

## 第三幕：数字员工（10 分钟）——上传 → 分析 → 产物 → 下载

1. 拖一个 Excel 进聊天（附件上传）→ `@小码 分析这个附件并导出 Excel 报告`
2. 看消息卡片：📋 认领角标 → 工具调用卡片（参数可见）→ 汇报带数据
3. 话术："沙盒里跑 pandas，每一步可展开查看"
4. Agent 详情 → 文件区 → 看到生成的 report.xlsx → **下载**
5. 话术："上传到拿回成品报告，全程 2 分钟——这就是数字员工"

## 第四幕：协作与记忆（5 分钟）——AI 像同事

1. 追问：`@小码 为什么华东区最严重？` → 深入归因（三重叠加：唯一负增长/降幅最大/占比高）
2. 话术："它区分'数据证明的事实'和'推断'——不会编"
3. 再问：`@小码 咱们群里之前关于华东 Q3 有哪些共识？` → 引用群共识记忆
4. 话术："群里的结论它记得——下次开会不用重复背景"
5. 数据纠错：`数据对吗？我这边看是 40%` → 核对 → "您的 40% 是对的 ✅"
6. 话术："它把你当同事——称呼、核对、承认、修正，和真人一样"

## 第五幕：治理与成本（3 分钟）——可批可查可控

1. 审批：Agent 配置开启分级审批 → 发一个删除类任务 → 看审批待办 → 批准/拒绝
2. 审计：Agent 日志（工具调用记录）→ 话术："每一步可审计，合规场景的底线"
3. 成本：Dashboard → 本月节省 ROI → **导出价值报告**（HTML 可打印 PDF）
4. 话术："试用 14 天，到期我给你一份这样的报告——AI 替你干了多少活、省了多少钱"

## 第六幕：安全与部署（2 分钟）——私有化兜底

1. 话术："沙盒 Docker 隔离（--cap-drop ALL）、IM 回调验签、租户隔离审计、
   SSO/License/白标——采购问卷必查项我们有一份文档交完"
2. 部署：docker compose up -d + healthz（展示 deployment.md 交付三件套）

## 演示 Q&A 备查

| 客户问题 | 回答要点 |
|---------|---------|
| AI 会不会乱来？ | 沙盒隔离 + 分级审批 + 审计——高风险操作人批了才执行 |
| 成本可控吗？ | 答案缓存（相似问题零 token）+ 月配额 + 80% 告警邮件 + ROI 报告 |
| 数据安全？ | 私有化部署 + BYOK（模型用你们的 Key）+ 租户隔离 + GDPR 删除 |
| 员工会用吗？ | 在钉钉/飞书群里 @ 机器人就行——用他们已有的工具 |
| 和钉钉 AI 有什么区别？ | 我们能碰文件/跑命令/出产物（沙盒）、审批治理、私有化——钉钉 AI 不能 |

## 关键演示话术（一页）

> "这不是聊天机器人——这是**给你团队加了一个会干活的同事**。
> 他在群里知道谁是谁、记得群里的决定、接活认领、干活汇报、出错道歉、
> 每一步可批可查、产物交付到文件、成本每周算给你看。"
