# weifuwu 设计语言 2.0 —— 微流明（MicroLucid）

> 状态：定稿（2026-08，plans/04-design-quality P0）
> 定位：WUI Design Language 的"面孔"——五条理念（确定性/清晰/克制/专业/中文原生）是
> **品格**（正确性），三支柱是**面孔**（独特性）。品格保证专业，面孔保证记忆。
> 背景：用户反馈"没有眼前一亮"——设计系统正确但缺乏可识别性；weifuwu 的三重身份
> （AI SaaS 框架 / 微服务架构哲学 / 开发者工具）是独特性的来源。

---

## 1. 命名与宣言

**微流明（MicroLucid）**——"微"是微服务的微（模块边界）、"流"是 AI 原生的流
（流式/渐进/可中断）、"明"是开发者工具的明（可推导/诚实/透明）。

```
没有主流设计语言同时拥有这三个身份——这就是 weifuwu 的独特性：
  微服务的边界 · AI 的流动 · 开发者的透明
```

## 2. 三支柱

### 支柱一：微 · 边界即结构（Boundary as Structure）

| 项 | 内容 |
|----|------|
| 身份 | 微服务架构——模块边界清晰、服务自治、契约接口 |
| 视觉签名 | **1px 细边框是设计主角**——结构用边界线表达（层级 = 表面 + 边界组合），而非阴影堆叠 |
| 对比 | antd/Geist 用阴影卡片堆叠；weifuwu 用"结构线"——界面有清晰的骨架感 |
| 落地 | `--wf-surface-*` 三层 + border token 体系（已有）；组件分隔优先 border；浮层边界线 |
| audit | 组件 CSS 层级表达优先 border（P11-R35 box-shadow 全 token 化已约束阴影滥用） |

### 支柱二：流 · 进行态语言（State as Stream）

| 项 | 内容 |
|----|------|
| 身份 | AI 原生——流式/渐进/可中断/进度透明 |
| 视觉签名 | **"进行中"是可见的流**——流式渐显（内容逐段进入）、thinking 脉冲、进度透明；AI 组件专属动效家族 |
| 对比 | 其他库 loading 是"转圈"；weifuwu 是"流动的进行态"——AI 界面活着 |
| 落地 | `--wf-motion-*` 扩展（stream-in 渐显 / thinking-pulse 呼吸 / streaming-cursor）；AI 组件统一引用 |
| 已有 | ReasoningBlock 流式脉冲 / AiChat 流式 token 渐显 / 进度组件透明 |

### 支柱三：明 · 可解释表面（Explanatory Surface）

| 项 | 内容 |
|----|------|
| 身份 | 开发者工具——可推导性 by construction / 诚实裁剪 |
| 视觉签名 | **层级/状态/数据可读**——状态链完整可推导（hover→focus→pressed→disabled）、浮层暗色抬升可见、语义色只表达语义、数据身份可见（data-wf-key/id 落 DOM） |
| 对比 | 设计也诚实：不炫技、无魔法样式（与 vdom 可推导性同哲学） |
| 落地 | 状态层 token（已有）+ 浮层抬升（已有）+ 数据可见性（已有） |

## 3. 与五条理念的合并（品格 + 面孔）

```
五条理念（品格）：确定性 · 清晰 · 克制 · 专业 · 中文原生
三支柱（面孔）：  边界即结构 · 进行态语言 · 可解释表面

映射：
  确定性   ← 可解释表面的状态链完整
  清晰     ← 边界即结构的三层表面 + 三档文字
  克制     ← 细边框美学（轻阴影）+ 动效短促有目的
  专业     ← 进行态语言（AI 工具感）+ 数据密度
```

## 4. 视觉签名规范（可识别特征）

### 4.1 细边框美学（边界即结构的落地）

```
□ 组件/分区/浮层的结构表达优先 1px 边框（--wf-color-border 系）
□ 阴影仅用于"抬升"语义（浮层/拖拽中）——不用于静态卡片装饰
□ 层级 = 表面层（--wf-surface-1/2/3）+ 边界线组合
□ 浮层边界线显式（暗色下抬升底色 + 边框——Material 色调层级借鉴）
```

### 4.2 流式动效家族（进行态语言的落地）

```
□ stream-in：内容渐显（opacity + translateY 4px——AI 回复/流式列表）
□ thinking-pulse：思考呼吸（已有 ReasoningBlock 模式——组件化统一）
□ streaming-cursor：流式光标（AI 输出中的 ▍ 闪烁——ChatInput/AiChat 统一）
□ 时长走 --wf-dur-*（120-300ms）· reduced-motion 自动降级
```

### 4.3 可解释层级（可解释表面的落地）

```
□ 状态链四态完整（hover/focus-visible/active/disabled）——audit 已强制
□ 语义色只表达语义（-text 变体）——audit 已强制
□ 浮层暗色抬升（bg-elevated）——audit 已强制
□ 数据身份可见（data-wf-key/id）——已落地
```
