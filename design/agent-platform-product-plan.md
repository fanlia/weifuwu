## 1. 八角色优化意见

### 1.1 老板（商业价值）

| 意见 | 理由 |
|------|------|
| **锁定差异化定位：企业级「人机协作曲」**——钉钉的群聊形态 × Coze 的 Agent 编排，主打「真实员工 + AI 同事同群协作、AI 发言可审批」 | 竞品（Coze/Dify/扣子）全是个人工坊，企业协作 + HITL 审批是差异化空位 |
| **模板市场是获客钩子**——11 个角色模板（开发/客服/产品/数据/运营）直接对应企业岗位，做成「复制即用」 | 降低首因体验门槛（实测创建 Agent 走模板 2 步） |
| **Token 消耗 = 成本视图 = 商业卖点**——Dashboard 已有 token 统计，升级为「按 Agent/部门/成员的成本报表」 | 企业采购关心 ROI；这也是唯一可收费的增值项 |
| MVP 不做：多模型供应商切换、Agent 市场交易、低代码编排画布（剪裁，避免摊薄） | 聚焦「群聊协作」单点打透 |

### 1.2 用户（使用体验）

| 意见 | 理由 |
|------|------|
| **注册后立即有「第一个 AI 同事」**——注册时可选模板直接建 AI 机器人（默认建 user agent 已有，补 AI 引导） | 新用户 3 步内体验 AI 对话，避免「建公司→建部门→建 Agent→加成员」4 重门槛 |
| **聊天主路径可及性**——侧边栏「聊天」应直达会话列表（最近会话），而非「发起聊天」选择页 | 微信/钉钉心智：打开就是最近会话 |
| **@ 定向发言**——`@开发助手小明 帮我查一下…` 只有被 @ 的 AI 回复；无 @ 时全部 AI 回复 | 多 AI 群不刷屏；语义清晰 |
| **无 AI 成员反馈**——群内无 AI 成员时发送后系统提示「该群组没有 AI 成员，去添加」+ 一键跳转 | 消除静默失败（P1-2） |
| **消息搜索 + 会话内 @ 成员补全**（输入 `@` 弹成员选择） | 会话历史可查；@ 输入低成本 |

### 1.3 产品经理（需求/功能完整性）

| 意见 | 理由 |
|------|------|
| **补齐成员管理闭环（P1-1）**：部门详情「添加成员 / 移除成员」；群主可管理；这是群聊产品的最低可用边界 | 后端 API 已有，纯前端补 UI |
| **公司级成员归属**：company 目前只有名字，无成员/负责人概念——补 company 成员管理（或明确剪裁为「组织顶层仅容器」） | 组织模型完整性；避免后续返工 |
| **部门创建流程整合公司**：无公司时部门创建页内嵌「快速创建公司」或引导跳转（P0-2） | 流程断裂修复 |
| **会话持久化视图**：最近会话列表（部门 + 最后消息 + 未读） | 群聊产品核心导航 |
| **webhook/KB Agent 引导**：两种 agent 类型创建后无「如何使用」引导（webhook 文档/KB 上传提示） | 长尾类型激活率 |
| **需求剪裁（诚实裁剪，CS-05）**：不做文件群发/语音视频/消息已读回执——聚焦文本协作 | 避免摊薄 |

### 1.4 视觉设计师（视觉规范）

| 意见 | 理由 |
|------|------|
| **修复侧边栏溢出（P2-2）**：用户名/邮箱 truncate 需容器 min-width:0 + ellipsis 链；「产\n产品经理小王」暴露布局断链 | 第一视觉印象 |
| **登录/注册页视觉升级**：AuthPage 单卡居中已达标；补品牌渐变背景/产品 slogan 区 | 首因体验 |
| **聊天页信息层级**：消息气泡间距/时间戳弱化/工具卡样式统一（当前时间戳同字号并列，工具卡 wf-bg-brand 偏重） | 阅读舒适度 |
| **Dashboard 趋势可视化**：补真实 7 天折线/柱状图（组件库有 Chart？——无则用 CSS 柱条） | 数据面板可信度 |
| **暗色模式适配走查**（组件已支持，产品未启用开关） | 企业用户夜间使用 |

### 1.5 交互设计师（可用性）

| 意见 | 理由 |
|------|------|
| **键盘可达**：聊天发送 Ctrl+Enter（ChatInput 已支持？）；Esc 取消编辑；成员列表键盘导航 | OPTIMIZE-PLAN 遗留项 |
| **@ 成员补全交互**：输入 @ 弹成员浮层（键盘上下选 + 回车插入） | 定向发言低成本 |
| **审批流提示**：HITL 待批消息在管理员侧应有**独立待办入口**（当前只能刷聊天流找「草稿待审批」卡） | 审批可达性（产品价值核心） |
| **加载反馈**：页面 fetch 失败显示错误态 + 重试（当前多数 `.catch` 静默置 loading=false 空白） | 错误可见性 |
| **空态引导**：各部门/聊天空态带下一步 CTA（部分已有） | 新手引导 |

### 1.6 前端开发者（工程质量）

| 意见 | 理由 |
|------|------|
| **P0-1 修复 + 同类排查**：`ctx.api.get().then(改状态)` 漏 `rerender()` 是 render-only 纪律通病——全量 grep 排查各页面 then/catch 对称性 | 已实测抓到 1 处；防同类 |
| **P2-1 AuthPage 受控警告**：AuthPage 内部 AutoComplete 受控缺 onChange——框架组件用法 bug（组件侧给 warning 是对的——消费方用法错）——产品改用非受控或补 onChange | console 噪音 + 交互隐患 |
| **Chat.tsx 拆分（~450 行）**：拆 MessageList/MessageItem/ToolCard/ApprovalCard 子组件 | 可维护性（OPTIMIZE-PLAN 遗留） |
| **统一 $ 状态模式**：各页面手写 `const $: Record<string, any>` + rerender——提炼 `usePageState` 或保持但加类型 | 类型安全（`any` 蔓延） |
| **前端测试缺位**：README 诚实裁剪「页面 JSX 测试需 esbuild 编译链路」——可考虑 ui-dom/testing 原语做组件级测试（框架已有 renderVNode/mountComponent） | 回归防线（框架能力未复用） |

### 1.7 后端开发者（架构/安全/性能）

| 意见 | 理由 |
|------|------|
| **@ 定向回复**：chat.ts 解析 `@agent名` → 只触发目标 agent；未匹配则全部（兼容现状） | P1-3 修复 + 新能力 |
| **消息拉取分页**：`/messages` 全量拉取（无 limit）——长会话 OOM 风险 | 性能红线 |
| **并发/幂等**：AI 回复任务无并发锁——同部门连发多条会并行跑多个 agent run（可能乱序）；补 per-department 串行队列或消息版本号 | 一致性 |
| **Webhook 安全**：签名校验已有；补 replay 防护（timestamp + nonce）与请求体大小限制 | 企业安全 |
| **审批权限**：`POST /messages/:id/approve` 当前任何群成员可批——应限管理员/发起人 | 权限模型 |
| **搜索**：消息全文搜索（`to_tsvector` 或 LIKE）——P2 产品需求 | 会话可查 |
| **成本控制**：per-agent 月度 token 限额（超额停 AI 回复）——老板视角增值 | 商业 |

### 1.8 运营经理（增长/留存）

| 意见 | 理由 |
|------|------|
| **模板市场运营位**：角色模板页加「推荐/热门/新」排序 + 使用次数计数（数据已可采集） | 内容运营抓手 |
| **注册引导漏斗**：注册成功 → 引导创建第一个 AI 机器人（3 步内达成「首次 AI 对话」）——埋点记录漏斗 | AARRR 激活率 |
| **内置示例场景**：预置 1 个「客服中心」demo 部门（含知识库 Agent + 智能客服）开箱即体验 | 秒级价值感知 |
| **数据埋点**：agent 创建/消息数/对话成功率的租户级统计（Dashboard 已有雏形） | 运营决策数据 |
| **文档/帮助中心**：产品内嵌「如何使用」（模板说明 / @ 用法 / HITL 说明） | 自服务降低客服成本 |

## 3. 实施计划（Wave 划分）

### Wave 1 — 阻断修复 + 流程闭环（P0）
1. NewAgent rerender 修复（已改）——**全量 grep 各页面 `then(` 后状态变更有无 rerender**
2. 部门创建页：无公司时显示「快速创建公司」内嵌表单或一键跳转（消除 API 文案）
3. 侧边栏 truncate 修复；Dashboard 趋势假数据修正（至少展示真实 7 天消息柱条）

### Wave 2 — 群聊核心（P1）
4. 部门详情成员管理 UI（调已有 API：POST/DELETE /members）
5. 无 AI 成员系统提示 + 一键去添加
6. 会话列表页（侧边栏「聊天」→ 最近会话：部门名/最后消息/时间）
7. 审批待办入口（未批 ai_draft 聚合列表 + 直达跳转）

### Wave 3 — AI 会话智能（P1-P2）
8. @ 定向发言：chat.ts 解析 @名 + 前端 @ 补全浮层
9. 消息分页（`LIMIT/OFFSET` + 前滚加载）；消息搜索
10. 审批权限收紧（管理员/发送者可批）

### Wave 4 — 商业与运营（P2-P3）
11. Dashboard 成本视图（按 Agent token 排行）+ 趋势图
12. 注册引导创建第一个 AI 机器人 + 示例客服部门
13. 模板使用计数 + 推荐排序
14. 埋点（激活漏斗：注册→建 Agent→首次对话）

### Wave 5 — 工程（P3）
