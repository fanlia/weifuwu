# vdom 测试覆盖标准（真实覆盖度评估）

> 纪律来源：**多次「充分测试」声明后被真实例子抓出 bug**（insert ref=null
> 语义/占位塌缩/keyed 误判冲突重建/A 级检测误报——mapping.test 抓出 4 个）。
> 根因：测试从**实现反推**（固化实现行为）而非从**契约正推**（规范推导）；
> 覆盖的是**路径**而非**语义空间**；缺**独立于实现的不变量标准**。
>
> 本文件是 vdom/core 测试的**覆盖度评估标准**——写测试前对照，评估覆盖
> 时对照——「全绿」不是充分性的证据，「规则→测试映射 + 不变量断言 +
> 转化闭环」才是。

---

## 1. 三层覆盖标准（缺一不可）

### 1.1 规则表 → 测试矩阵（可审计）

`design/vdom-transform-rules.md` 的**每条规则**（用户可推导性）→ 至少一个
测试。矩阵维护：新增/修改规则 → 矩阵同步新增行。

```md
| 规则 | 测试（文件:用例） | 断言面 |
| --- | --- | --- |
| 空洞 = 注释占位（同构） | node/hole.test:render 集成 | DOM 长度 |
| 数组第 i 项 ⟷ childNodes 第 i 个 | mapping.test:首帧 | 位置 |
| 同 key 复用项 DOM 引用不变 | mapping.test:keyed 增 | 引用 |
| ... | ... | ... |
```

**审计方式**：grep 规则表 → 每个「应该」对应测试名。

### 1.2 DOM 不变量断言（强制——每个渲染测试）

**每次渲染后**（首帧/转化/导航）必须断言的不变量——提取公共 helper
`assertIsomorphic`（见 §2），禁止只查存在性：

| 不变量 | 断言 | 抓出的 bug |
| --- | --- | --- |
| **同构**：childNodes.length === children 数组长度 | 占位锚 ↔ 真实节点互换长度恒定 | 占位塌缩（13≠14） |
| **位置**：数组第 i 项 ⟷ childNodes 第 i 个 | 位置 0 空洞→元素在首位 | insert ref=null append 错位 |
| **引用**：同 key/同位置复用项 DOM 节点引用不变 | keyed 增后旧 li 引用 | keyed 误判冲突重建 |
| **资源**：remove/done 后事件表/ref 表/portal 容器清理 | 无残留 | removePortal 容器残留 |
| **可逆**：转化往返后回到原 DOM 状态 | A→B→A 后 B 输出 + 长度一致 | 双向转换只测单向 |

### 1.3 转化闭环（双向 + 往返 + 边界位置）

每个 A→B 转换必须测：

1. **正方向**（A→B）——命令 + DOM 结果
2. **逆方向**（B→A）——回到原状态（可逆性）
3. **多次往返**（A→B→A→B→…）——状态不漂移（每次往返后 DOM 与首次一致）
4. **边界位置**：位置 0 / 中间 / 末尾 三处至少各一（位置 0 是数组边界——
   插入语义与中间不同——真实 bug 多发区）
5. **组合**：核心特征两两同页（portal×keyed / fragment×条件 / 数组×组件 /
   条件×组件切换）——mapping.test 模式系统化

## 2. 公共断言 helper（测试基建——禁止手抄）

`src/client/vdom/testing/`（或 setup 扩展）：

```ts
/** 同构断言：container childNodes 与期望序列形态一致（长度 + 位置 + 类型） */
export function assertIsomorphic(
  container: HTMLElement,
  expectShapes: Array<'element' | 'text' | 'hole' | string>,  // 按序
  opts?: { holes?: string[] },  // 期望空洞内容
): void

/** 引用断言：同 key 复用项 DOM 引用不变 */
export function assertKept<T extends Node>(
  container: HTMLElement, selector: string, before: T,
): asserts before is T

/** 资源断言：事件表/ref 表/portal 容器清理（无残留） */
export function assertNoLeak(applier: CommandApplier, id: string): void
```

## 3. 测试分层（黑盒优先）

| 层 | 断言面 | 用途 |
| --- | --- | --- |
| **黑盒（DOM 结果）** | 位置/长度/引用/内容——不依赖命令 | **主要**——契约验证 |
| **命令流（白盒）** | 精准性（counter 只 setText） | 辅助——性能/最小命令 |

命令流断言不能替代 DOM 断言（命令对但 DOM 错位 = 白盒盲区）——每个命令
流断言必须伴随同场景的 DOM 结果断言。

## 4. 新增测试检查单（提交前过一遍）

- [ ] 测试验证的是**规则表**（规范）还是实现现状？（实现现状 → 先修实现）
- [ ] 带 `assertIsomorphic`（长度 + 位置）？
- [ ] 带引用保持断言（复用场景）？
- [ ] 双向 + 往返（转化场景）？
- [ ] 边界位置（位置 0 / 末尾——至少一处）？
- [ ] 资源清理断言（卸载/关闭场景）？

## 5. 覆盖度评估流程（每次宣称「充分」前）

1. 规则表逐条对测试矩阵——**未映射规则 = 未覆盖**（不接受「间接覆盖」为
   唯一证据——间接覆盖允许但必须标 `[间接]` 且矩阵注明）
2. 不变量四类（同构/位置/引用/资源）在核心场景（首帧/条件渲染/列表/浮层/
   导航）各至少一次
3. 转化闭环：每个转换对的往返次数 ≥ 1
4. 边界位置：位置 0 场景存在
5. **红队演练**：写一个「用户角度」的随机例子（含组合特征 + 边界位置 +
   双向往返）跑一遍——新 bug = 标准未满足（回到 1）
