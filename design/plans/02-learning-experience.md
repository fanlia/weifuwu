# 02 学习体验计划（Learning Experience）

> 目标：需求驱动的完整学习阶梯——零基础开发者从"知道 weifuwu"到"做出复杂应用"无断层。
> 现状：积木层强（146 组件 + 活体 + 18 指南），场景层/方法论层缺。

## 目标与验收

```
目标：学习者的每一步都有承接——需求 → 场景 → 组件 → 布局 → 页面 → 应用
验收：
  □ 组件搜索可用（/components 全局过滤——跨分类找组件）
  □ 需求目录上线（"我要做 X" → 模板/场景/组件全链路映射）
  □ 新手 30 分钟从需求到可运行页面（hello-world → 模板改 → 跑起来）
  □ 组件文档「典型场景」节覆盖高频 40 组件
```
